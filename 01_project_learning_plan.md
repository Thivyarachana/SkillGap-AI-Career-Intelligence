# Beginner learning plan

1. Run `python src/clean_data.py`
   Learn: read_csv, columns, missing values, duplicates, type conversion.

2. Run `python src/analysis.py`
   Learn: groupby, value_counts, explode, matplotlib, seaborn.

3. Run `streamlit run app.py`
   Learn: sidebar widgets, pages, metrics, charts, session state.

4. Open Power BI and import `data/cleaned_jobs.csv`.
   Learn: data model, visuals, slicers, measures.

5. Test the chatbot.
   Learn: text input, intent matching, recommendations.

6. Replace the sample CSV with a real dataset and document the source.

7. Push to GitHub and deploy with Streamlit Community Cloud.
